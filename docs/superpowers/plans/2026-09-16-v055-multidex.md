# ZERO v0.5.5 Multi-DEX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scan and represent cross-venue opportunities across Uniswap V3, Sushi V3, and Camelot Algebra V3 on one pinned Arbitrum block.

**Architecture:** Add a venue-adapter interface and a registry. V3-compatible adapters share factory discovery logic; Camelot has a dedicated Algebra adapter. Route identity includes venue IDs, and exact quote support is venue-specific.

**Tech Stack:** Python 3.11, JSON-RPC, Aave V3, Uniswap V3, Sushi V3, Camelot Algebra V3.

**Spec:** `docs/superpowers/specs/2026-09-16-zero-roadmap-completion-design.md`

## Global Constraints
- Exact pinned block for all venue reads.
- No remote writes.
- Unsupported quote/execution venues cannot produce executable candidates.
