# ZERO v0.5.6 Multi-Hop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate and evaluate bounded cyclic routes of up to three swaps across enabled venues.

**Architecture:** Build a deterministic token/venue graph from pinned pool refs, enumerate simple cycles that start/end in the flash asset, and quote each leg sequentially so each next amount uses the previous exact output.

**Tech Stack:** Python 3.11, dataclasses, Decimal, venue adapters.

**Spec:** `docs/superpowers/specs/2026-09-16-zero-roadmap-completion-design.md`

## Global Constraints
- Maximum three swap legs.
- No repeated pool in a route.
- Start and end asset must match flash asset.
- Candidate must remain positive after flash premium, gas, reserve and all exact quotes.
